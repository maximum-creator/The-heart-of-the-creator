# 活跃问题与伏笔模板

## 活跃问题

| ID | 读者会问什么 | 依据 | 情感利害 | 首次出现 | 最近推进 | 下一窗口 | 状态 |
|---|---|---|---|---|---|---|---|

状态：建立 / 收窄 / 转化 / 回答 / 放弃并闭合

## 伏笔证据

| ID | 对应问题 | 当场自然功能 | 表层解释 | 回看解释 | 知情角色 | 首次出现 | 强化记录 | 回收窗口 | 状态 |
|---|---|---|---|---|---|---|---|---|---|

状态：种下 / 强化 / 静默 / 再激活 / 局部回收 / 完整回收 / 作废并解释

## 回收验收

- 答案是否能从既有证据与人物选择推出，而非临时补设定？
- 是否改变人物选择、关系、资源、身份或风险？
- 是否让至少一处旧信息重新估值？
- 是否留下与答案相称的余波？
