# 运行模式

## FAST

适用：普通过渡章、上下文清晰、无高风险事实。

最小团队：故事架构师或主智能体生成章节包 → 正文作者 → NovelOS MCP 重复扫描。扫描或主智能体发现风险时，才调用对应审稿 Agent。

## STANDARD

适用：重要关系变化、关键承诺兑现、复杂场景、近期数据下滑。

最小团队：故事架构师负责事件因果；人物情感导演负责欲望、误解和情绪节拍；正文作者综合；硬逻辑审计和读者体验审查各自只给差量；正文作者完成一次定向修订。

## DEEP

适用：新书、卷级设计、高潮反转、历史/制度核心情节、连续失败后的策略重建。

1. 创意室生成至少两条机制不同的路线，不做同义改写。
2. 研究编辑独立核验市场或事实，不读取创意路线的结论性评价。
3. 主智能体以人物因果、长期生产力、番茄阅读动力、事实可行性和预算综合选择。
4. 只深化胜出路线；其余进入灵感库，不继续烧 Token。

## 升降级

- HARD 事实未知、Canon 冲突、关键章情绪失败：升级一级。
- 风险解除且下一次调用不会改变决定：立即停止升级。
- 单次审稿只出现局部 P1：不升级，执行一次局部修订。
- 不因“想做到更好”无限升级；必须指出下一次调用要验证的具体假设。
