# AI 叙事结构风险登记表

这不是永久禁令，也不是“像人公式”。只用于发现模型反复选择的省力路径；只有它确实损害本书读者契约时才修。

| 风险 | 文本证据 | 对读者的损害 | 最小修正方向 |
|---|---|---|---|
| 主题和道理被旁白解释完整 |  | 读者失去参与解释的空间 | 删总结，让选择与后果表达 |
| 单线整齐、支线只作装饰 |  | 世界像为主角搭台 | 让配角目标产生真实干扰或代价 |
| 主角低能动性 |  | 推进靠系统、巧合、情报投喂 | 关键进展改由有限信息下的选择促成 |
| 严格顺时、旧信息不再估值 |  | 可预测，缺少“原来如此” | 用后果或新事实改变旧细节意义 |
| 冲突及时闭合、过早总结 |  | 没有关系余波和长期牵引 | 留下具体未消化后果，不强塞事故钩子 |
| 升级曲线平坦 |  | 事件变大但体验相同 | 改变阻力类型、选择难度或胜利代价 |
| 善恶与动机过于整齐 |  | 人物像论点而非人 | 增加符合经历的矛盾动机，不等于全员灰色 |
| 身体反应代替情绪过程 |  | 人物共享同一副身体 | 改写为私人解释、回避、误判和行为余波 |
| 每个场景都完成纲要考点 |  | 人物没有自主偏移 | 允许目标冲突改变场景落点，但保留主线功能 |
| 连续使用同一揭示或章末机制 |  | 读者提前预测节奏 | 改变信息来源、兑现方式和后果形态 |

## 审查原则

1. 先看目标读者是否真的受损，再看是否符合风险名称。
2. 不为降低“AI 检测率”而洗稿；修正叙事选择，不做近义词替换。
3. 不机械增加闪回、多视角、支线或道德暧昧。
4. 每章最多处理一个主风险；跨章复现才进入长期错题本。
