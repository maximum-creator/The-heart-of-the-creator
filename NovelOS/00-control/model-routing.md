# 模型路由

机器佳源为 `NovelOS/00-control/capability-model-map.json`。FeelFish 当前覆盖和自定义方案由 `NovelOS/tools/config/sync-model-routing.mjs --write` 从该映射同步；岗位更换模型时只改映射文件，再运行同步与拓扑检查。下表是人读说明，不是第二配置源。

## 升级门禁

- FAST 不多模型会审；STANDARD 只调用改变决策的专业 Agent；DEEP 才做短方案发散。
- 正文作者若在固定测试集持续出现模板句、情绪平或角色同声，再对同一 Chapter Packet 用候选模型做盲测；不凭模型名长期绑定。
- 便宜模型先做完整性、重复模式和状态检查；强模型只接收命中的段落与证据，不读取整本书。
- 昂贵调用前先用 `novelos_cost_estimate` 检查计费数据是否齐全，并写出唯一假设。工具返回 `canAuthorizeSpend: false` 时不得把历史混合值当预算通过；只有单次请求日志可闭合实际费用。
- 任意付费正文发送还必须经过 `paid-run-authorization-gate.mjs`：模型、正文舱哈希、准确分项费率、思考/重试设置、单次预算与15分钟内当次确认缺一即停。该回执必须继续绑定进章节总门，不能发送后补写授权。
- 新会话首次正文调用以及方案/Agent 切换后，先运行 `NovelOS/tools/config/check-agent-overrides.mjs`。它检查 `.feelfish/solution.json` 是否漂移，并核对 FeelFish 最新持久化会话是否创建于当前方案之后、是否绑定当前 solutionId 与主 Agent；旧会话或错误主 Agent 都返回 `BLOCK_MODEL_CALL`，禁止发送。
- 每章记录实际模型、调用阶段、失败原因、是否改变决策和可保留改进；没有质量收益的调用从流程删除。
- 前三章逐章做跨模型质量门禁；稳定后默认每 5 章抽检 1 章。重大转折、新视角、读者数据异常、E1—E24 命中或用户不满意时立即恢复检查。
- GLM-5.2、Qwen Max、Seed Pro、GPT Terra 等高价模型不得整本读取、不得承担状态抄写，也不得在同一段上连续接力重写。
- DeepSeek V4 工作日北京时间 09:00—12:00、14:00—18:00 约为 2 倍积分；非紧急批量任务优先避开该时段。是否等待由交付时限决定，不为省积分耽误必须发布的章节。
- 官方工程、推理或上下文基准不能证明小说写得更好；人物、正文和审稿模型的分工都只是先验，必须由同一任务信封的匿名稿与实际积分日志修正。

预算公式与停止条件见 `NovelOS/00-control/cost-budget.md`。

每次更换模型，记录日期、版本、原因，并使用 `NovelOS/09-evals/quality-regression-cases.md` 与 `model-benchmark.md` 做匿名回归。质量提升不能覆盖新增成本时不替换默认模型。

## 2026-09-02 实测修正

- `deepseek-v4-flash` 的 T05 格式、长度和基础节奏合格，但泄漏顾川限知视角，且闻岚的离场动作未改变窗口证据；保留为最低成本初稿，不获得发布资格。
- `qwen3.7-plus` 的 T05 超长，并将“只能判断码是否复制”扩成触觉读微结构、共振记忆和药物真假判断，还凭空生成全息结构；不得作为正文挑战者晋升。
- `feelfish/M2.5` 仍是未验证先验；当前正文选择器中未找到该精确模型，`xiaomi-mimo-v2.5` 不是 MiniMax，禁止混用结论。
- 本轮无模型通过 T05 人工硬门，因此不替换正式路由；真正降低有效成本的优先项是缩短上下文和加强写前/写后硬门，不是继续堆昂贵模型。
- 积分随后从 435,016 延迟刷新到 1,546,330，快照差额 1,111,314，远超界面倍率估算；所有付费正文挑战者已关闭，恢复条件见 `cost-budget.md` 的延迟结算保护。
- T06 后续核对发现：方案文件虽推荐正文作者关闭思考，但项目运行时 `.feelfish/solution.json` 把该 Agent 覆盖为 `enableThinkingMode: true`、`reasoningEffort: high`。这解释了界面中的显式思考与长推演。运行时覆盖已修正为 `false` 并移除高推理字段；此修复只消除已知配置浪费，不证明下一次调用便宜或质量合格。
- T09 在 `enableThinkingMode: false`、空会话、无 MCP 条件下仍产生 10,206 completion Token、1,402,663 积分实扣和可见规划泄漏。`novelos-prose-writer + feelfish/deepseek-v4-flash` 已写入 `model-route-blocklist.json`；关闭思考不再视为放行条件。
- T10 将正文 Agent 压至 774 字符并移除全部 Skill/工具，使用 710 字符 Packet 与 `xiaomi-mimo-v2.5-pro`。FeelFish 编辑部表面仍注入 5,253 字符 system 与 6,020 字符 user 上下文；模型在关闭思考时展示规划，并把明确纸币组合算错。网页单次明细确认输入 5,656、输出 3,400、缓存命中 36.2%，实扣 453,490 积分。该路由已隔离。
- 正文生产的下一候选不是继续轮换编辑部模型，而是独立 FeelFish 正文舱中的辅助创作面板：上游 Agent 只负责生成压缩 Packet，正文舱不包含项目树、Agent、Skill、研究库或整本历史。`preflight-prose-panel.mjs` 通过后也只到 `READY_FOR_AUTHORIZATION`，发送时仍须重新取得单次积分授权。
- 当时的 T11 预案曾把 `feelfish/deepseek-v3.2` 设为唯一候选；该旧预案未授权、未运行，已被下方“新模型优先修正”取代，不得据此发送。

## 2026-09-04 互联网模型证据修正
