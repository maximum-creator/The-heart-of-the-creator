# NovelOS 能力开关与动态组队

系统默认关闭一切非必要能力。总导演先判断任务、缺口和证据，再启动会改变本轮决定的最小团队；Agent、Skill、MCP 和模型不是固定流水线。

## 四层隔离

1. **决策层**：总导演只分类、分流、验收和控制预算，不写正文。
2. **设计层**：市场、长线、单章、人物各自产出候选差量；叙述视角和情感压力在这一层进入因果，不是事后润色。
3. **正文层**：正文作者只接收闭合 Packet、必要的上一章尾段和本章事实边界；只挂 `novelos-chapter-writing`，无工具、无 MCP，不读取整本项目。
4. **验证层**：确定性工具先判硬门；工具不能判断的读者体验才交一个独立编辑。路由成熟后由系统自动验收，用户只在里程碑和异常时参与。

## 能力开关矩阵

| 缺口或任务 | 唯一主责 | 常驻 Skill | 可用工具/MCP | 启动条件 | 关闭条件 |
|---|---|---|---|---|---|
| 普通续写 | 章节架构师 | chapter-planning | 只读当前状态；必要时 context-pack | 当前章目标明确 | Packet 闭合即停 |
| 新书/平台机会 | 市场策略师 | market-selection | 只读研究事实卡 | 新书、平台变化、连续数据异常 | reader-contract 形成即停 |
| 总纲/卷纲/高潮 | 故事架构师 | long-arc | 无默认 MCP | 长线承诺或结构会改变 | 胜出路线和故事债登记即停 |
| 人物/关系关键场 | 人物导演 | natural-prose | 无 MCP | 关系不可逆、人物失真、配角可删除 | 人物差量交回即停 |
| 当前事实/时事/史实 | 研究编辑 | evidence-research | internet/fetch/knowledge 按命题启用 | 信息会改变行动且事实卡不足 | 来源卡 READY/BLOCKED 即停 |
| 时间/金额/能力/知识审计 | 硬逻辑审计员 | continuity-audit | 先读本地硬审计回执 | 专业事实、复杂账目或工具命中 | P0/P1/UNKNOWN 报告即停 |
| AI 轨迹/读者体验 | 叙事编辑 | surgical-revision | 只读统一评测报告 | 确定性门通过但有一个主要体验损失 | 一张局部修订单即停 |
| 项目快照/重复/事实/成本/章节总验收 | 工具管理员 | token-economy | 仅挂 NovelOS MCP | 总导演给出明确工具目标或章节证据齐备 | 带哈希回执落盘即停 |
| 定稿状态与学习 | 状态管理员 | state-learning | 无 MCP | 人工批准或生产态自动验收 | 差量提交后即停 |

## 动态配方

### FAST：普通章

章节架构师生成 Packet 与最多3项状态转移边界 → 正文作者一版 → 统一确定性质量门。无专业事实、无跨章异常、无核心关系变化时，其余 Agent 和全部 MCP 关闭。门禁全过后，章节验收总门重读并哈希绑定全部原始产物；只有总门返回 `ACCEPT_AUTONOMOUS_STATE_COMMIT`，状态管理员才用同一次差量提交正式状态，不为了“更好”追加编辑。

### STANDARD：关键章

章节架构师与人物导演各自读取有限事实，分别给出场景因果和人物差量 → 总导演合并成一个 Packet → 正文作者一版 → 确定性门。只在报告指出一个主要损失时调用叙事编辑；硬逻辑风险只调用硬逻辑审计员。不得两个编辑接力重写。

### DEEP：立项、卷级、高风险章

研究编辑产出事实卡；市场策略师与故事架构师在不互相抄结论的前提下提出机制不同的短方案；人物导演只验证关键角色是否会真实行动；总导演选择一条路线并停止其余分支。正文仍回到 STANDARD/FAST，不把研究会话带进正文。

## 失败回退

| 失败 | 回到哪里 | 禁止做法 |
|---|---|---|
| 原始回复含推理/自评/规则回声 | 执行表面或模型路由 | 脚本剥离后冒充通过 |
| 金额、时间、能力或专业事实错 | 事实契约/章节架构 | 让正文模型补一句圆场 |
| 配角可删除、情绪平、对白说明书 | 人物发动机/场景阻力 | 换同义词、加握拳和眼神 |
| 节奏慢但事件很多 | 章末状态与选择后果 | 加弹窗、加危机、切短句 |
| 连续章节同构 | 对手策略、信息顺序、代价 | 只换开场词或章末装置 |
| 成本超信封 | 上下文、模型或任务拆分 | 同配置重试或专门预热 |

## “人味”验收证据

每章必须能在正文中定位：关键人物的私人解释、一次有代价的选择、配角造成的因果变化、情绪余波、至少一种不可逆状态变化，以及由本章选择自然产生的下一步动力。叙述必须受视角人物的知识、注意力和关系影响，不能是全知模型的通用播报。跨三至五章检查开场、胜利机制、身体载体、信息揭示和章末方式是否重复。词语命中只触发复审，不能直接洗稿。
