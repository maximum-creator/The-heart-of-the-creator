# 本书章节字数与排版验收

默认每章 2000—2500 汉字，不计章名、标点、数字及外文字符，超出范围进入复审，不强制凑字或截断。此默认值已由项目所有者授权采用，不是平台统一规定。单本书有明确要求时覆盖同目录 chapter-length-policy.json；导入默认值不代表以后不能调整。

- version：1。
- metric：han 只统计 Unicode 汉字；visible 统计非空白 Unicode 字符，包括标点、数字、外文和表情。两种口径都不等同宿主或平台的计费字数。
- min/max：大于零的整数，包含上下边界。不计标题行；输入必须符合“首个非空行是章名，后续为正文”的交付协议。
- enforcement：review 表示超范围转复审；reject 表示本书明确要求的硬范围。不要为凑数机械扩写或删改。
- approved：只有用户确认了本书范围后才设 true。没有确认时统计照常返回，但不会报字数达标或自动批准。

统一章节验收默认读取运行根目录下 NovelOS/00-control/chapter-length-policy.json。若本轮证据使用独立运行目录，可在验收输入中以 chapterLengthPolicy 指定目录内的策略文件路径。显式路径无效或 JSON 损坏直接拒绝，不悄悄忽略。每次回执保存策略文件哈希；字数结果绑定最终稿原始字节哈希，不能复用修改前的结果。

独立候选稿检查使用 --length-policy 指定上述 JSON；未提供目标会返回 CHAPTER_LENGTH_NOT_CONFIGURED 复审项，阻止自动状态提交。这不是要求重新调用写作模型，而是补齐本书目标后用同一最终稿重新检查。

排版新增单段超过 300 字符的定位提醒，原连续长段、碎段和标点检测保留。300、120、15 等是内部排查阈值，不是番茄官方规定；命中只进入语境复审，不自动切段或替换标点。手机行数受屏幕和字号影响，字符阈值不等于实际显示行数。

市场版没有这些程序检查。它只交接本书目标、提示使用宿主字数统计，并进行原文复核；无精确结果就标待核，不声称机器通过。完整版的本地合成测试也不能证明用户的 FeelFish 已调用工具，需当前项目真实回执另证。
