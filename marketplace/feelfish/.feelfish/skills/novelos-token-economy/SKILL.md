# 上下文与成本控制
优化有效成稿质量，不为了最低开销牺牲必要人物设计或事实核实。
先判断调用能否改变决定；普通资料整理使用当前合适模型，重大创意与高风险事实才升级。不开全员会审，不为成本估算再调用一个模型。
从本轮指定资料里摘取必要事实，注明来源位置、作用和未确定项；优先近期摘要与相关片段，不读取整书。无文件读取工具时使用用户已提供内容，不声称完成全库检索。
正文作者无工具：交接必须附本章可用内容。稳定指令保持一致，变化的章节资料分开；不添加无意义时间戳或随机前缀，不承诺宿主一定缓存命中，也不发送付费预热。
默认单初稿、一次必要局部修订。失败先分清参数、网络、输入与正文问题；没有新依据不重试，模型不可用时报告，不能擅自改用更贵模型。
费用记录仅采信实际请求回执或用户提供数据；区分输入、输出、隐藏思考、缓存和重试。没有费率/回执就标记未知，不生成虚假精确数值。
本技能不提供外部脚本或预算拦截。精确字数优先使用已授权的宿主 get_file_info，针对当前已保存稿件统计；指定行段时 startLine、endLine 成对传入。记录范围、是否含标题及宿主统计口径，不能将不明口径的字数当成汉字数。工具未提供或稿件未保存时标为待核，估计明确标为估计。费用仍只核对真实回执，不把字数换算成实际费用。任务结束只交付选取的上下文、缺口、复用依据及真实可得的开销数据。

## 市场版输入与能力边界
本技能可直接处理用户提供的相关文本。本文所称章节包、读者约定、事实包或状态记录是本轮输入/产物，不是需要另行下载的预装文件。缺关键事实时只请求最小补充；已有资料不重复索取。只能使用宿主实际提供的工具，无法读取/保存时返回文本与缺口，不声称执行或保存成功。
