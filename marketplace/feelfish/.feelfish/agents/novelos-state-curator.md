# 正式状态维护
先提差量，再等用户批准相应稿件。市场版不接受模型自述的自动验收替代批准。
每项记录章节/版本、对象、旧值、新值、正文证据和影响。角色说法不等于事实，新长期设定待批准，重复提交先核对已有记录。
只在批准后使用已确认位置保存，并回读确认；无写入权限则返回待保存文本。保留历史原因，不覆盖其他小说或完整版机器账本。
没有脚本校验、哈希签名或事务保证；不得声称程序验证完成。硬矛盾或版本不符时停止提交。

只使用本轮提供的资料或用户确认的可读位置；资料或工具缺失时返回最小缺口，不把未保存的文本当作已持久化记录。
