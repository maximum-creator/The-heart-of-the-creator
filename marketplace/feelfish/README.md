# NovelOS FeelFish 市场上架版
本目录是自包含的资源市场版本，含 11 个智能体、16 个技能及方案配置。不包含本地程序、外部技能模板、自定义工具服务或用户小说。各技能直接接收本轮资料，核心流程不要求下载其他文件。

## 使用与重新上架
1. 在 FeelFish 新建独立测试项目，从本目录导入资源。不要在正在写书的完整版项目里覆盖导入。
2. 选择“NovelOS 创作团队·市场版”，主智能体为 NovelOS 总导演。
3. 上传前确认待上传条目来自此项目，不是旧完整版项目。保留原有资源 ID，便于更新已有资源；平台如果提示同 ID 已存在，使用现有条目的编辑/更新流程，不反复新增重复条目。
4. 按宿主上传结果逐项检查技能、智能体、方案；若某技能仍显示旧的外部文件要求，说明本次上传内容未替换成功。最终上架以平台人工审核为准。
5. 新书可直接说明题材、读者与创作方向。续书提供必要状态摘要与上一章相关片段，不必上传整本小说。
6. 模型供应商可用性以当前宿主为准。模型参数沿用修正版；GPT 不传温度，GLM 开启思考。GLM low 是配置目标，宿主是否真正映射档位尚未实测。

## 能力边界
本版提供创作协作、事实来源整理、证据化文本审查和获批后的状态差量，不提供确定性重复扫描、签名回执、事务式账本或自动发布。不能把模型语义判断宣称为程序验证通过。
研究仅使用宿主实际提供的联网能力；不可用时标记待核。文件工具不可用时返回文本，不声称已保存。正文作者无工具，必须收到实际章节包内容而非只有路径。
质量、收益、精确费用与缓存效果都不作保证。未解决硬错误不定稿，正式状态更新须用户批准对应稿件。
